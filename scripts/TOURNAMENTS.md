# Регистрация турнира

В `scripts/tournaments.json` хранится JSON-массив дополнительных турниров. Для каждого укажи `key` (уникальное латинское имя для ссылки), `name` (отображаемое название), числовые `league_id` из OpenDota и `stage_id` из Cybersport. Поле `bracket_ids` — необязательный массив числовых ID сеток Cybersport. Заполни его, если в одном этапе есть квалификация и основной турнир. Без фильтра попадут все сетки этого этапа. PARI Universe и оба этапа 1win уже подключены.

После изменения файла в ветке `main` процесс Deploy static dashboard проверяет подтверждённые пары, время, формат серии и сыгранные карты. Тот же процесс запускается по расписанию, в том числе при закрытом браузере. Для немедленной повторной проверки доступен ручной запуск этого процесса в GitHub Actions.

Сетка берётся из зарегистрированного этапа Cybersport. Для результата сверяются матчи лиги OpenDota, команды, время, порядок карт и счёт серии. Когда счёт лиги недоступен, проверяется отдельная карточка игры и её статистика. Карта с противоречивыми источниками остаётся в ожидании подтверждения. Уже подтверждённые результаты сохраняются при сбоях источников. Сторонние названия и коды турниров сами по себе не связывают карту с прогнозом.

Для исходных PRE и POST турнир также должен обслуживаться моделью трекера. К сбору публичного расписания и результатов это требование не относится.
